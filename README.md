# 墨迹 · 纯前端博客系统（含管理后台）

一个**零依赖、零构建、零后端**的博客系统。全部由原生 HTML + CSS + JavaScript 写成，
数据保存在浏览器 `localStorage` 里，Markdown 在本地实时渲染。

打开 `index.html` 就能用，不需要 `npm install`，不需要服务器，不需要数据库。

---

## 快速开始

### 方式一：直接打开（最简单）

双击 `index.html`，或者用浏览器打开它。

> 部分浏览器（尤其是 Safari）对 `file://` 协议下的 `localStorage` 有额外限制。
> 如果发现刷新后数据丢失，改用下面的方式二。

### 方式二：起一个本地静态服务（推荐）

任选一条命令，在 `blog/` 目录下执行，然后访问提示的地址：

```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx serve .

# PHP
php -S localhost:8080
```

### 方式三：部署到静态托管

把 `blog/` 整个目录上传到 GitHub Pages / Vercel / Netlify / 对象存储即可，
没有任何构建步骤。

## 目录结构

```
blog/
├── index.html          博客前台（hash 路由单页）
├── admin.html          管理后台
├── css/
│   ├── style.css       前台样式（浅色 / 深色双主题）
│   └── admin.css       后台样式
├── js/
│   ├── store.js        数据层：localStorage 读写、统计、导入导出、登录
│   ├── markdown.js     零依赖 Markdown 渲染器（含 XSS 防护）
│   ├── app.js          前台：路由与视图
│   └── admin.js        后台：登录、文章管理、编辑器、设置、备份
└── README.md
```

四层职责清晰，互不耦合：**store.js 不认识 DOM，markdown.js 不认识数据**，
两个视图层只调用 `window.Blog` 和 `window.Markdown`。

## 管理后台

访问 `admin.html`。

| 项 | 值 |
| --- | --- |
| 默认密码 | `admin123` |
| 登录态 | 保存在 `sessionStorage`，关闭标签页即失效 |
| 修改密码 | 后台 →「修改密码」 |

后台功能：

- **仪表盘** —— 文章数、草稿数、分类标签数、累计阅读、总字数，以及最近更新
- **文章管理** —— 搜索、按状态/分类筛选、分页；一键发布 / 下架 / 删除
- **写文章** —— 左侧 Markdown、右侧实时预览；标题、slug、分类、标签、封面、摘要、状态
- **分类与标签** —— 新增 / 重命名 / 删除（重命名会同步更新所有文章）
- **站点设置** —— 站名、副标题、作者、描述、页脚、备案号、每页文章数、默认主题
- **数据备份** —— 导出 / 导入 JSON，一键恢复演示数据
- **快捷键** —— 编辑器内 `Ctrl/Cmd + S` 保存

### 编辑器小细节

- 新建文章时会自动把内容存为**本地草稿**，误关页面后回来可恢复，也可以一键丢弃
- 标题失去焦点时自动生成 slug
- 离开编辑器时若有未保存内容会二次确认
- Markdown 工具栏：标题 / 加粗 / 斜体 / 代码 / 链接 / 列表 / 引用

## Markdown 支持

渲染器是手写的，只依赖字符串操作，约 300 行。

| 语法 | 说明 |
| --- | --- |
| `#` ~ `######` | 标题，自动生成锚点 id |
| 空行分段 | 段内换行渲染为 `<br>` |
| `**粗体**` `*斜体*` `~~删除线~~` | 行内样式 |
| `` `行内代码` `` | 单行代码 |
| ` ```lang ` … ` ``` ` | 围栏代码块，带语言标签 |
| `-` / `1.` | 无序、有序列表，支持缩进嵌套 |
| `- [x]` / `- [ ]` | 任务列表 |
| `>` | 引用，支持递归嵌套 |
| `\| a \| b \|` | 表格，支持 `:---:` 左右居中对齐 |
| `---` | 分割线 |
| `[文字](url)` `![alt](url)` | 链接与图片（外链自动 `target="_blank"`） |

**安全处理**：所有文本先整体做 HTML 转义再拼接标签；链接协议过滤掉
`javascript:` / `vbscript:` 以及非图片的 `data:`。所以文章内容里的
`<script>` 只会以文本形式显示。

## 数据存储

| 项 | 说明 |
| --- | --- |
| 存储位置 | `localStorage`，key 为 `dshm_blog_db_v1` |
| 主题偏好 | `localStorage` 的 `dshm_blog_theme` |
| 编辑器草稿 | `localStorage` 的 `dshm_blog_editor_draft` |
| 登录态 | `sessionStorage` 的 `dshm_blog_auth` |
| 容量 | 约 5 MB，纯文本足够用；**不要把图片转 base64 存进来** |

数据层的设计要点：

1. **内存兜底** —— 隐私模式下 `localStorage` 会抛异常。每次写入都包在 `try/catch` 里，
   失败时退回内存对象并提示用户，页面不会崩溃。
2. **结构自愈** —— 读取时统一走 `normalize()`，缺失字段补默认值、类型不对就修正，
   旧版本数据不会让页面白屏。
3. **导出即备份** —— 后台「数据备份」可以导出完整 JSON，换设备时导入即可。

> ⚠️ 纯前端方案绕不开的限制：**内容只属于当前浏览器**。
> 清理浏览器数据、换设备、换浏览器，内容都不会跟着走。请养成导出备份的习惯。

## 定制

配色、圆角、字体都在 CSS 顶部的变量里，改一处全局生效：

```css
:root {
  --accent: #0f7b6c;      /* 主色 */
  --radius: 14px;         /* 圆角 */
  --maxw: 1080px;         /* 内容宽度 */
  --font-serif: Georgia, "Songti SC", serif;  /* 标题字体 */
}

html[data-theme="dark"] {
  --accent: #35c3ac;      /* 深色模式主色 */
}
```

站点名称、副标题、作者、页脚等在**后台 →「站点设置」**里改，不需要动代码。

## 常见问题

**Q：忘记后台密码了怎么办？**
A：密码以散列值存在 `localStorage` 里，无法反推。打开浏览器控制台执行
`localStorage.removeItem('dshm_blog_db_v1')` 后刷新即可重置（**会清空全部内容**），
或者用之前导出的 JSON 备份恢复。

**Q：能多人协作 / 多端同步吗？**
A：不能。这个项目定位是纯前端演示与个人轻量使用。需要多端同步就得接后端，
但 `store.js` 已经把数据读写收敛成一层接口，替换成 HTTP 请求即可。

**Q：登录密码安全吗？**
A：不安全，也不应该被当作安全措施。它是纯前端的「防误触」屏障——
任何人都能在控制台里读到数据。**不要用它保护真正敏感的内容。**

**Q：文章里的图片怎么处理？**
A：填外链 URL。封面和图床都只存 URL，不存二进制。

## 浏览器支持

Chrome / Edge / Firefox / Safari 的现代版本，以及鸿蒙、iOS、Android 上的主流浏览器。
用到了 `CSS 变量`、`Grid`、`color-mix()`、`Object.assign`、`NodeList.forEach`、
`Element.closest` 等特性。`color-mix()` 是较新的特性，旧浏览器上导航栏背景会退化为透明，
不影响功能。
